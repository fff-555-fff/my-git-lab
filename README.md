# Distributed Version Control Experiment - Lab02

## Project Overview
This repository is created for the Lab02 Distributed Version Control experiment, designed to demonstrate basic Git operations and collaboration workflows.

## Directory Structure
- `.gitignore`: Git ignore rules configuration
- `README.md`: Project documentation

## Experiment Steps
1. Create a local repository and link it to the remote GitHub repository
2. Create `.gitignore` and a standard-formatted `README.md`
3. Commit files and push them to the remote repository
4. Create a new branch, modify the file, and merge it into the main branch (collaboration workflow)
